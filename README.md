O brief completo (estrutura, nomes, o que é bruto, inventário e passo a passo) está em [CLAUDE.md](CLAUDE.md). Abra uma sessão do Claude Code nesta pasta e ele já carrega o brief.

```powershell
git clone <url deste repo>
cd organizar-hds
claude
```

`referencia/Organizar-HDs_v1.ps1` é o script de 24/10/2026. Ele serve só como mapa de onde as coisas estavam e como modelo de código seguro. A estrutura nova está no CLAUDE.md.
